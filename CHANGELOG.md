# Changelog

Keenpix releases are generated from GitHub tags with [`changelogithub`](https://github.com/antfu/changelogithub).

Tag releases with semantic versions in the form `vMAJOR.MINOR.PATCH`, for example:

```bash
git tag v0.1.0
git push origin v0.1.0
```

The release workflow publishes GitHub release notes and the Docker workflow publishes matching GHCR image tags.
