## External blockers and known limitations

- Field Core Web Vitals and organic/search baselines cannot be claimed until real data accumulates.
- Google's GTM malware scanner false-positively paused the built-in Google tag. The container version is published and linked, but analytics collection is not claimed until Google clears the automated pause.
- Polar sandbox checkout/webhook E2E requires a cloud-owned staging callback. The sandbox webhook must not deliver to the production application.
- Polar production benefit attachment requires the documented installer to run with the runtime token. Coolify's web terminal selected the exact cloud app container but did not establish an interactive shell, so no apply was attempted.
- Cloudflare routing, TLS, caching, and SEO behavior are verified, but the optional application-side Cloudflare analytics environment variables are unset; the dashboard therefore cannot split edge versus origin metrics yet.
- Customer proof, reviews, benchmarks, certifications, and competitor facts will not be invented; absent evidence remains explicitly absent.
- Takumi is available in the repository for deterministic OG rendering. Raster image generation will use the approved built-in image capability because no separate Takumi image-generation service is exposed.
- The PR will not be merged without explicit user instruction.
- Actual migration/cutover, legacy data inspection, and legacy routing changes require a later explicit user instruction.
