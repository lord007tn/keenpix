Keenpix exposes a single endpoint. No API key — the project's allowlist is the access
control.

```http
GET /api/keenpix?project=PROJECT_ID&url=SOURCE_URL&w=…&fmt=…
```

| Part      | Required | Notes                                                       |
| --------- | -------- | ----------------------------------------------------------- |
| `project` | yes      | Project id; its allowlist gates access. Missing → `400`.    |
| `url`     | yes      | Absolute source URL. Host must be allowlisted. Missing → `400`. |
| transforms| no       | `w`, `h`, `q`, `fmt`, `fit`, `dpr`, `blur` — see [Parameters](/docs/reference/parameters). |

## Example

```bash
curl -I "https://keenpix.example.com/api/keenpix?project=store&url=https://cdn.example.com/hero.jpg&w=800&fmt=webp"
# HTTP/1.1 200 OK
# content-type: image/webp
# cache-control: public, max-age=31536000, immutable
# vary: Accept
# x-keenpix-cache: MISS
```
