Keenpix is an image-optimization service you can use two ways — [managed cloud](https://keenpix.com)
at keenpix.com or [self-hosted](/docs/self-hosting) on your own infrastructure — and an
open-source alternative to
[ImageKit](/blog/keenpix-vs-imagekit), [imgix](/blog/keenpix-vs-imgix), and [Cloudinary](/blog/keenpix-vs-cloudinary). Its public transform API is a single HTTP endpoint that fetches an image from
your origin, transforms it with [sharp](https://sharp.pixelplumbing.com) (resize,
crop, filter, and re-encode), optimizes SVG explicitly with `fmt=svg`, caches the
result on disk, and serves it behind a long-lived, immutable `Cache-Control`.

There's no SDK to install and no API key in your image URLs — **a request is just a URL**:

```html
<img
  src="https://keenpix.example.com/img/https://cdn.example.com/hero.jpg?project=PROJECT_ID&w=1200&fmt=auto"
  alt="Hero"
/>
```

## Why Keenpix

- **Drop-in.** Any framework that renders an `<img>` works — no rewrite required.
- **Cloud or self-hosted.** Use the managed cloud at keenpix.com, or run the same engine as a single container on your own infrastructure; put a configured CDN in front of it.
- **Keyless.** Access is gated by a per-project domain allowlist, not by secrets.
- **Built-in analytics.** Every origin request is logged, and optional Cloudflare edge analytics show the cache layer in front.
