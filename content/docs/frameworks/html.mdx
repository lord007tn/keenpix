Because Keenpix is just a URL, it works with no framework at all — and with any
server-side language (PHP, Ruby, Python, Go, …). Build the URL and render an `<img>`.

## Static HTML

```html
<img
  src="https://keenpix.example.com/api/keenpix?project=YOUR_ID&url=https://cdn.example.com/hero.jpg&w=1280&fmt=avif"
  sizes="100vw"
  loading="lazy"
  decoding="async"
  alt="Hero"
/>
```

## Responsive with `srcset`

```html
<img
  src="https://keenpix.example.com/api/keenpix?project=YOUR_ID&url=https://cdn.example.com/hero.jpg&w=1280&fmt=auto"
  srcset="
    https://keenpix.example.com/api/keenpix?project=YOUR_ID&url=https://cdn.example.com/hero.jpg&w=640&fmt=auto   640w,
    https://keenpix.example.com/api/keenpix?project=YOUR_ID&url=https://cdn.example.com/hero.jpg&w=1280&fmt=auto 1280w,
    https://keenpix.example.com/api/keenpix?project=YOUR_ID&url=https://cdn.example.com/hero.jpg&w=1920&fmt=auto 1920w
  "
  sizes="100vw"
  alt="Hero"
/>
```

## Server-side (example: PHP)

```php
<?php
function keenpix(string $src, int $w): string {
  $q = http_build_query(['project' => 'YOUR_ID', 'url' => $src, 'w' => $w, 'fmt' => 'auto']);
  return "https://keenpix.example.com/api/keenpix?$q";
}
?>
<img src="<?= keenpix('https://cdn.example.com/hero.jpg', 1280) ?>" alt="Hero" />
```

The same one-liner works in Rails, Django, Laravel, or a CMS template — just URL-encode
the `url` parameter.
