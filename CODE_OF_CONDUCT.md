# Code of Conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be respectful, assume good intent, and keep discussions focused on the work. Disagreement is fine; personal attacks, harassment, discrimination, and bad-faith conduct are not.

## Scope

This applies to issues, pull requests, discussions, commit messages, and any other repository interaction, as well as when representing the project publicly.

## Reporting

Report violations privately through the maintainer contact listed on the repository owner's GitHub profile. Reports will be reviewed promptly and kept confidential.
