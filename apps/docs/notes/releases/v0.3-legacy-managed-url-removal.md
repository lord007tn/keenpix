# v0.3 managed URL removal

Keenpix v0.3 removes the legacy first-party managed URL:

```text
https://keenpix.com/img/<source>?project=<project-id>
```

The supported managed URL is:

```text
https://cdn.keenpix.com/p/<project-id>/img/<encoded-source>
```

## Implementation status

- Framework packages expose `createManagedKeenpixConfig(projectId)` and encode the complete source value.
- The SDK configuration endpoint, dashboard quickstart, framework guides, and cloud quickstart emit only the canonical form.
- Managed signed URLs keep project attribution in the signature through `signatureParams` without exposing `?project=` publicly.
- v0.3 responds to the removed first-party form with `410 Gone`, `Deprecation: true`, and a `Link` header containing the canonical replacement.
- Self-hosted and verified custom-domain `/img` URLs are unchanged; their query/hostname project resolution is not the removed managed route.

## Release gate

Before tagging v0.3, search source, generated docs, package examples, and built assets for `keenpix.com/img` and fail the release if an emitter remains. Keep only the v0.3 migration note and regression tests that intentionally mention the retired form. Verify a canonical managed URL reaches the edge directly, a signed canonical URL verifies after edge project injection, and the legacy first-party form returns `410` with the correct successor link.
